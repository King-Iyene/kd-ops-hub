Onboarding & Core Navigation
Welcome to KDOps
First-time user experience — from login to orientation on the dashboard and sidebar.
Scenes: Login screen → enter credentials → dashboard loads → tour the sidebar items → explain role-based visibility → profile dropdown → notification bell → sign out
Routes: /login / /profile
Troubleshooting: Can't log in? → Use "Forgot Password" to reset via email. Still stuck? → Contact your admin to resend the invite link. · Seeing "Unauthorized" page? → Your role may not have access to that section — ask admin to check your role assignment. · Notification bell not loading? → Refresh the page; if persistent, clear browser cache.
~3.5 min Start here All roles
Dashboard Command Centre
Reading the operational pulse — health score, cash burn, tasks, compliance deadlines, and quick actions.
Scenes: Health score card breakdown → cash burn + runway → my tasks widget → stat cards row → recent activity feed → compliance card → upcoming subscriptions → budget utilisation donut chart → quick action buttons
Routes: /dashboard
Troubleshooting: Health score showing 0 or unexpected value? → Check if compliance filings, documents, and budgets have been set up — the score draws from all modules. · Stat cards showing ₦0? → No approved expenses or processed payments this month yet. · "Complete your setup" wizard won't dismiss? → Finish all 3 setup steps first, or click the ✕ to hide it.
~4.5 min Start here Managers
2
People & Team Management
Managing Employees
Add, edit, and manage your team — roles, contact info, and the employee directory.
Scenes: Employee list overview → search → add new employee (name, email, phone, role) → role badges explained → edit employee → status changes
Routes: /employees
Troubleshooting: New employee can't log in after being added? → They need a separate invite email — adding to the directory doesn't create their auth account. Ask admin to send invite. · Wrong role assigned? → Edit the employee and change their role; they'll see updated sidebar on next login. · Employee not appearing in assignee dropdowns? → Check their status is active, not deactivated.
~3 min Core Admin / Ops
Contractor Directory
Managing external partners — bank verification, bulk CSV import, and payroll-ready records.
Scenes: Contractor list → add contractor (name, bank, account number) → Paystack bank verification flow → bulk CSV import with validation → CSV export → deactivate/reactivate
Routes: /contractors
Troubleshooting: Bank verification failing? → Double-check account number (10 digits) and ensure the correct bank is selected. Paystack may be temporarily down — try again in a few minutes. · CSV import rejecting rows? → Check the template format: full_name, bank_name, account_number, default_amount columns required. Remove blank rows. · Contractor not appearing in payment batch? → Ensure their status is "active", not deactivated.
~3.5 min Core Managers
Leave Requests
Requesting and approving time off — annual, sick, and other leave types.
Scenes: Leave overview + balance cards → submit a request (type, dates, reason) → manager approves/rejects → status tracking → search and filter
Routes: /leave
Troubleshooting: Leave request stuck on "pending"? → It needs manager/admin approval — check with your manager. · Can't select dates? → Ensure start date is before end date, and both are in the future. · Balance not updating after approval? → Refresh the page; balances recalculate on page load.
~2.5 min Standard All roles
Tasks & Accountability
Creating tasks, assigning team members, tracking progress, and the comment thread.
Scenes: Task board overview (stats: my/open/overdue/completed) → create task (title, assignee, due date, priority) → scope filter (mine vs all team) → mark complete → open task detail → comment thread → priority and status badges
Routes: /tasks
Troubleshooting: Task not showing up for assignee? → They must have a manager role (admin, finance, operations) to see the Tasks page. · Overdue count wrong? → Tasks with past due dates and status other than "complete" count as overdue — mark completed tasks done. · Comments not saving? → Check your internet connection and refresh.
~3.5 min Core Managers
3
Financial Operations
Payment Batches — End to End
The full payment lifecycle: draft a batch, select contractors, verify banks, submit, approve, fund, and process.
Scenes: Payment list → "New Batch" → Step 1: batch details → Step 2: select contractors + add one-off beneficiary with Paystack verification → Step 3: review summary → save draft vs submit → batch detail page → approval flow → confirm funded → process payments → per-item status → CSV export → printable receipt
Routes: /payments /payments/new /payments/:id
Troubleshooting: Can't submit batch for approval? → Batch must have at least one beneficiary with a verified bank account. · One-off beneficiary bank verification timing out? → Paystack API may be slow — wait 10 seconds, then retry. · Payment stuck on "Processing"? → Individual items may have failed — check per-item status and use "Retry failed" button. · "Reject" not available? → Only super_admin, admin, and finance roles can approve/reject. · Receipt not printing? → Ensure pop-up blocker isn't blocking the new tab.
~6 min Core Finance
Expenses & Approvals
Submitting expenses, category breakdown, bulk approval, and the unified approvals inbox.
Scenes: Expenses overview + stat chart → submit expense (category, amount, description) → expense appears in Approvals inbox → approve/reject single → bulk approve with checkboxes → CSV export
Routes: /expenses /approvals
Troubleshooting: Expense not appearing in Approvals inbox? → Make sure it was submitted, not saved as draft. · Bulk approve button greyed out? → Select at least one item using the checkboxes. · CSV export empty? → Check your filters — you may have a status filter hiding results.
~4 min Core All / Finance
Payroll Intelligence
Monthly payroll drafting — auto-pulling expenses and payments, PAYE/Pension estimates, and the burn trend.
Scenes: Payroll stats (total burn, PAYE, pension) → burn trend bar chart → draft payroll for a month → review auto-computed figures → submit → approve → mark paid → CSV export → printable report
Routes: /payroll
Troubleshooting: "Draft payroll" showing ₦0? → No approved expenses or processed payment batches for that month yet — approve pending items first. · PAYE/Pension estimates seem wrong? → Estimates use fixed rates (PAYE 8%, Pension 8%, NHF 2.5%) — adjust manually if your company uses different rates. · Can't submit payroll? → Must be in "Draft" status first. · Printable report blank? → Allow pop-ups in your browser for ops.kdsquares.com.
~4 min Core Finance
Budgets & Subscriptions
Budget planning with approval workflow, plus recurring subscription tracking and renewal alerts.
Scenes: Budget list → create budget → approval workflow → lock/unlock → Subscriptions page → stat cards → add subscription (vendor, category, cycle, renewal date) → mark renewed → renewal notification alerts → CSV export
Routes: /budgets /subscriptions
Troubleshooting: Budget locked and can't edit? → Only super_admin can unlock budgets. · Subscription renewal not advancing? → Click "Mark renewed" — it auto-advances the next renewal date by one billing cycle. · Renewal alerts not showing? → Notifications are generated at 7/3/1 day marks — check the notification bell.
~3.5 min Standard Finance
4
Operations & Compliance
Compliance Centre
Nigerian statutory deadlines — PAYE, Pension, VAT, WHT — tracking, filing, and the calendar export.
Scenes: Compliance overview (overdue/due/upcoming/filed stats) → filing table with countdown badges → add new filing → auto-computed due dates → mark as filed → CSV calendar export
Routes: /compliance
Troubleshooting: Filings not auto-populating? → The system seeds last 3 months of monthly filings on first visit — if already visited with empty data, add filings manually. · Due date seems wrong? → Nigerian statutory due dates are auto-computed (e.g., PAYE by 10th of following month) — verify against FIRS/PenCom rules. · "Mark filed" not saving? → Check your internet connection and try again.
~3 min Core Finance
Fleet & Fuel Management
Fuel requests, trip logging, and the approval flow for field operations.
Scenes: Fleet page → Fuel Requests tab → submit fuel request (station, amount, litres, odometer, reason) → approval flow → Trip Logs tab → log a trip (start/end, distance, purpose)
Routes: /fleet
Troubleshooting: Fuel request not appearing for approval? → Only admin/finance can approve fuel requests — field staff and drivers can only submit. · Odometer reading rejected? → Must be a number greater than the last recorded reading for that vehicle. · Trip log missing? → Check you're on the "Trip Logs" tab, not "Fuel Requests".
~2.5 min Standard Ops / Field
Documents, Reports & Settings
File management, analytics dashboards, and super admin configuration.
Scenes: Documents page → upload file → role-based visibility → expiration tracking → Reports page → date range picker → chart tabs (payments, expenses, fleet, contractors, budgets) → CSV export → Settings page → company info → integrations (Airtable)
Routes: /documents /reports /settings
Troubleshooting: Document upload failing? → Check file size and ensure Supabase Storage isn't full. · Can't see a document? → It may be restricted to certain roles via "visible_to_roles" — ask admin. · Reports charts empty? → Adjust the date range — default is start of year to today. · Settings page not accessible? → Only super_admin can access Settings. · Airtable integration "Test Connection" failing? → Verify API key and Base ID are correct.
~3.5 min Standard Admin

Production Tooling

Remotion React-to-MP4 engine. Each video is a composition in the kdops-walkthroughs project.
Screenshots Captured from the live KDOps app via the browser pane, used as scene backgrounds.
KD Brand Accent #006994, cyan #00ECFF, gold #D6AC50. Logo badge on intros/outros.
Output 1920×1080 MP4 at 30fps. Each video standalone, no external dependencies.
Production order: Phase 1 first (onboarding videos set the tone), then Phase 3 (financial ops are the core value prop), then Phase 2 and 4 in parallel. Each video gets its own Remotion composition file in src/ of the kdops-walkthroughs project, rendered independently.
